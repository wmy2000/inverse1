# 8 GHz 双电控幅相超表面：CST候选单元 v0.1

## 0. 当前交付是什么

这是可以在本机CST中继续建模的**候选单元几何与验证流程**，不是已经全波优化成功的器件。云环境没有CST安装、接口或求解器，因此未生成真实求解后的`.cst`项目、S参数、幅相云图或加工文件。建模宏尚未在特定CST版本执行验证，菜单/API可能需按版本调整。没有用等效电路或虚构数据冒充CST结果。

根据你的选择，以8 GHz为目标，6–10 GHz为首轮频率范围。先做单元能力验证，再决定阵列；不直接制作16×16阵列。

本设计是受Self论文启发的简化“双层加载条形谐振器”研究起点，不是原论文精确复现，也未证明其自能调控机制或幅相解耦能力。原论文涉及更复杂的多模结构、开槽、粘接层和偏置网络，现有正文不能代替完整尺寸图/补充材料。若目标是忠实复现原论文，应另取得其尺寸与补充材料，不能用此宏替代。

## 1. 文件与推荐入口

- `BuildGeometry.bas`：CST内运行的VBA宏，只创建参数、材料、几何和频率范围。
- `geometry_history.vba`：同样的History命令片段，供Python接口或手动核对。
- `build_in_cst.py`：在本机已配置CST接口的Python环境创建并保存几何项目；不调用求解器。
- `parameters.json`：参数表及单位。
- `electrical_sweep_81.csv`：9个电阻×9个电容状态，电学扫描计划。
- `geometry_screen_27.csv`：27组几何预筛选，固定一个电学偏置；不能只靠这个偏置选出最终几何。
- `results_template.csv`：真实复反射数据汇总表头，无伪造数据。
- `analyze_states.py`：对真实导出数据生成状态云、幅相曲线和Jacobian指标。
- `candidate_geometry.png`：几何示意图，不是CST截图或仿真结果。
- `CST建模与验证操作说明.docx`：本说明的Word版本。

推荐先在CST GUI运行宏，手动创建两个集总元件和端口，用单状态求解确认设置。版本未知时不自动写入可能不兼容的Floquet和集总元件API。

## 2. 单元几何与参数

坐标单位mm；频率GHz；正入射从+z侧向−z传播；电场先选x极化。所有数值都是起始值，不是优化值。

| 参数 | 起始值 | 含义 |
|---|---:|---|
| p | 12 | 单元周期，8 GHz时约0.32λ |
| h1 | 1.5 | 地板到下层谐振器介质厚度 |
| h2 | 0.8 | 下层铜上表面到上层谐振器介质厚度 |
| tcu | 0.035 | 铜厚 |
| Lphase / wphase | 9 / 1.2 | 上层电容加载条带总长/宽 |
| Lamp / wamp | 10.5 / 1.2 | 下层电阻加载条带总长/宽 |
| gap | 0.4 | 两层中心加载间隙 |
| dy | 2.5 | 下层条带相对上层的y偏移 |
| epsr / tand | 3.55 / 0.0027 | 通用介质示例参数，不能视为某厂商实测材料 |
| Cload | 0.12–0.9 pF | 上层电容扫描范围 |
| Rload | 1–300 Ω | 下层电阻扫描范围 |

地板：z=−tcu至0。下介质：z=0至h1。下谐振器：z=h1至h1+tcu，沿x方向，中心y=dy。上介质：z=h1+tcu至h1+tcu+h2。上谐振器：z=h1+tcu+h2至h1+2tcu+h2，中心y=0。

每个谐振器由左右两段铜条组成，中心留gap，**没有**直接金属短接。下层器件位于内部，宏在上介质中留出2 mm×2 mm的访问开口。该开口只说明器件安装空间，尚未加入实际焊盘、封装和焊接工艺；真实层压/装配需要进一步机械审查。材料不是空气与介质的随意替换，开口必须保留在后续仿真中。

基线没有RF偏置线、过孔、扼流、电源和散热设计，因此仅用于单元原理筛选，不能直接出Gerber加工。非对称层移可能造成偏振耦合，必须测交叉极化。

## 3. 在CST GUI建立几何

1. 新建空白Microwave Studio高频3D项目，选择频域工作流程。设置mm/GHz；保存到新目录，不覆盖已有设计。
2. 在Macros相关菜单新建/打开VBA宏，加载`BuildGeometry.bas`并运行。不同版本的入口名称可能不同。
3. 检查模型树中`cell`组件，应包含地板、上下介质和四段铜条；上介质开口已通过Boolean subtract形成。
4. 检查参数表达式和每个实体范围，尤其铜条间隙没有被介质布尔操作误删或铜短接。
5. 宏若报错，保留报错行和版本信息，停止后续求解。可按该版本GUI录制同样的材料/几何操作后替换对应History命令。不能忽略错误后继续称建模完成。

也可在本机CST支持的Python环境中执行：

```text
python build_in_cst.py --output "D:\CST_projects\amp_phase_v0.cst"
```

脚本只创建几何并保存，不自动补齐集总器件或求解设置。普通Python不一定能import cst，请使用该版本官方安装文档中的接口配置；不要从不明来源安装同名包。

## 4. 手动增加集总元件：先理想、后寄生

使用CST的Lumped Element/集总RLC功能，类型选择**串联RLC**。这里不是离散激励端口，不需要新增外部馈电端口。

下层电阻支路连接点：

```text
P1=(-gap/2, dy, h1+tcu/2)
P2=(+gap/2, dy, h1+tcu/2)
```

上层电容支路连接点：

```text
P1=(-gap/2, 0, h1+tcu+h2+tcu/2)
P2=(+gap/2, 0, h1+tcu+h2+tcu/2)
```

使用正确的边/面连接选取，确保两端电气连接到左右铜条；若GUI拒绝实体内部点，可使用相应表面拾取，并用电流场检验连接。两端点不能落到介质、同一铜条或地板。

**v0理想扫描：**下层仅电阻R=Rload Ω；上层仅电容C=Cload pF。不需要某个串联元件时用GUI取消/禁用该元件，不要把串联电容设为0导致开路。检查工程中RLC数值单位，CST界面可能按F/H输入：0.4 pF=0.4e−12 F。

**v1寄生敏感性：**下层串联R=Rload、L=Lpin（起始0.4 nH）；上层串联R=Rvar（起始1.5 Ω）、L=Lvar（起始0.4 nH）、C=Cload。这些寄生只是敏感性示例，不是BAP70-02或MA46H120的已核验模型。最终用官方或测量器件模型替代，必要时加入并联封装电容和偏置网络。不得把Rload当成恒定线性的“电流到电阻”校准曲线；还需要实际I–R与功耗测量。

## 5. 周期边界、Floquet端口与参考平面

1. x/y设Unit Cell/周期边界，相移对应正入射0°；z方向使用本版本支持的Floquet单元反射配置，在+z侧设置Floquet端口。
2. 下方完整铜地板阻挡透射。可把zmin设电壁并与地板底面一致；若选其他边界须保留地板并证明下侧场不影响反射。避免对地板下方额外端口的错误S参数做解释。
3. +z端口位于上层金属上方约λ/4的空气区（8 GHz约9.4 mm）作为初始值，之后改变空气高度验证结果。空气区由背景/边界空间设置，不要与介质重叠。
4. 至少包含两个正交基模，识别电场沿x的入射模式并只激励该模式；记录同极化和交叉极化反射。不根据模式编号猜极化：正入射简并时TE/TM命名和编号可能变化。
5. 在周期12 mm、6–10 GHz、正入射下，高阶自由空间衍射一般不传播，但仍需按CST的模式截止信息核验；斜入射时重新检查。
6. 导出复数S参数前，统一参考平面到上层金属平面附近选定的固定z。若软件使用de-embed，先用PEC平面反射检查符号和往返相位。所有状态使用同一参考平面和同一极化定义。
7. 只用同极化S11不能计算真实吸收：有地板且只有两反射传播模式时，吸收≈1−|S_co|²−|S_cross|²。若存在其他传播模式，也需计入其功率。地板损耗和介质损耗也会吸收，并非全部是PIN损耗。

## 6. 求解器与网格：先一个状态再扫81个

使用Frequency Domain Solver和自适应网格（具体四面体/六面体按版本及单元边界支持选择）。首轮6–10 GHz包含8 GHz，先固定R=50 Ω、C=0.4 pF求解。

- 在gap、条带边缘、集总连接和开口处局部细化。0.4 mm间隙先考虑0.08 mm量级局部尺度，并比较更细网格；不要将整域均匀设0.08 mm。
- 35 μm铜若采用体网格会增加成本。可使用该版本支持的薄片/表面阻抗模型，但须与铜体模型做代表状态交叉验证。
- 自适应频点不能只覆盖一个状态的一个谐振：增加6、8、10 GHz附近检查，以及扫描出现尖锐谐振的位置；离散频点复查插值结果。
- 建议验收：连续加密后关键频点|S11|变化<0.01（线性幅度）、有效幅度点相位变化<2°，并检查功率平衡。A<0.1的状态相位不稳定，不适合用于严苛相位指标。
- 相位改变可能来自参考面/模式跟踪，先排除设置错误再宣称物理效应。

初筛不做27×81=2187组全交叉。顺序建议：单状态排错→3×3稀疏电学扫描→81状态基线→27组几何稀疏筛选→对前2–3种候选做81状态与寄生复核。CST参数扫描的mesh复用要检查每个几何的实际收敛，不能盲目复用不适配的网格。

## 7. 按什么指标判断单元值得继续

不是看一张好看的相位图。8 GHz优先检查：

1. **反射状态范围**：各状态实际A、φ及损耗；不要把所有R/C状态拼接出的相位范围当成等幅相位范围。
2. **固定C扫描R**：是否能明显改变幅度，且相位泄漏有限；分别报告各C处的幅度跨度和相位变化。
3. **固定R扫描C**：相位覆盖及其伴随幅度变化；不把大吸收点无定义的相位作为有效覆盖。
4. **二维可达域**：是否提供相位控制之外有价值的幅度自由度；排除细长的一维状态轨迹。
5. **归一化Jacobian**：对(A,φ/2π)关于归一化R/C求导、报告最小奇异值和条件数。R/C不是电压/电流，后续必须结合器件偏置曲线转换。
6. **偏振与角度**：交叉极化与±15°/±30°入射的状态变化，x/y两个入射平面分开检查。
7. **真实代价**：目标增益与损耗，不能只优化吸收带来的幅度范围。

候选筛选门槛可暂设为：有效状态中有≥240°的相位覆盖、部分相位附近能获得≥6 dB的幅度调节、相关电阻扫描相位漂移≤20°。这些是待协商的研发门槛，不是v0已实现或文献保证值；240°覆盖并非任意波束或定位任务必然足够。更严格的结论需要受限状态库下的系统收益。

若在8 GHz附近无有效谐振，先检查器件/端口连接，再增大或减小条带长度：长度增加通常降低主谐振，但多模耦合下非严格单调。若R变化几乎无影响，检查下层电流是否经过电阻；若相位和幅度严重耦合，调整dy、h2、两层长度差，再评估多模机制。候选双条带可能最终达不到解耦要求，届时应换耦合拓扑，而不是强行宣布成功。

## 8. 真实结果导出与分析

在CST中对每组状态导出同极化反射的**实部/虚部**，保留子载波/频率和偏置参数。用CSV合并为：

```text
frequency_GHz,Rload_ohm,Cload_pF,s11_real,s11_imag
```

不要把dB幅度直接填入实部。若导出的是dB与角度，先用S=10^(dB/20)·exp(j·phase_deg·π/180)转换；记录参考平面。每个频率、每个R/C组合只保留一行。

```text
python analyze_states.py actual_CST_results.csv --frequency 8 --out analysis_8GHz
```

需要NumPy和Matplotlib。脚本要求选定频点完整矩形R/C网格，不接受缺失/重复状态；输出state_cloud.png、amplitude_phase.png、jacobian.csv和summary.json。它不会自动宣布幅相解耦成功。相位覆盖使用离散样本最大圆周间隙法；9个C点可能低估连续覆盖，必须在相位快速变化位置进一步细扫。分析脚本不替代网格收敛、交叉极化、能量平衡或器件校准。

## 9. 单元之后怎样验证定位和抗干扰

只有获得真实可达状态后，才把Γ(f,R,C,θ)导入前一份研究方案的定位FIM/ML和通信SINR模型。不能继续使用任意单位圆内的理想权重。宽带时同一偏置对所有频率生效。

接着做4×4或8×8有限阵列，检查混合编码下的互耦误差：至少比较均匀、交替、梯度与随机编码。周期单元仅描述无限同态阵列，不保证混合编码局部模型准确。若采用等效阻抗边界加速，先用至少两种显式加载有限阵列检验一致性，再作为替代。

系统验证依次为：真实状态库的二维定位/干扰可控域计算→有限阵列近远场验证→偏置/寄生/角度误差鲁棒性→PCB样机与VNA标定→独立双源SDR通信。仅有CST周期S参数不能证明连续定位或真实抗干扰通信成功。
