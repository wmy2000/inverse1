## 1. 论文实际完成的工作

Hui Chu, Hanjun Zhao, Peng Li, Yong-Xin Guo. *Urban skies safeguarded: innovative drone detection with programmable metasurface periscope*. Nature Communications, 2024, 15:10375. DOI: 10.1038/s41467-024-54672-6。

论文正文第8页报告：载频3.35 GHz、FMCW带宽30 MHz、平均发射功率5 W；基带采样80 MHz，并记有4 µs delay；距离2048点FFT、速度512点FFT。64个扫描波束，角度间隔7.5°、驻留30 µs，覆盖方位/俯仰±30°。喇叭与PMS距离1.5 m。DJI Matrice 600以8/12 m/s飞行，距PMS约25 m至超过80 m，并验证正常和45°斜照射配置。

这些参数不构成完整时序：4 µs delay不能直接当chirp周期或PRI，30 µs驻留也不能直接当同波束慢时间采样间隔。需取得实际chirp/空闲时间、触发与扫描计划才能复现速度坐标。

30 MHz的常规距离分辨率约c/(2B)=5 m；2048点FFT不改变这个物理带宽限制。图7是样机与反射性能，图8是远场散射，图10才是无人机轨迹结果。

## 2. 压缩包里是什么

压缩包只有6个文件：RangeDopplerMap.m和Fig8a–e.csv。每个CSV均为144981×3，列名为：

```text
Phi[deg],Theta[deg],dB(DirTotal)
```

181个Phi点、801个Theta点；Phi为0–360°，Theta为−100–100°，使用前要确认CST/论文角度约定，不能直接当常规非负极角球坐标。

五个文件的最大方向性分别约14.63、14.17、13.17、14.38、12.44 dB。它们是CSV数值范围，不等于实测实现增益、RCS或雷达接收功率。没有相位、回波时刻、快慢时间、无人机坐标或速度真值。

这些数据可用于提取波束切片、覆盖包络、波束宽度与相对旁瓣，并在明确假设下作为链路的相对角度权重。DirTotal不能未经效率和绝对标定直接当成RCS/实现增益；无复相位也无法恢复相干回波或校正换码相位。数据未上传至本GitHub仓库，原附件保留在工作区。

原脚本没有读取CSV或实测IQ，只生成一个固定时延、恒定多普勒的合成目标。它没有直接模拟d(t)、距离迁移、无人机姿态RCS、多径杂波或桨叶微多普勒。固定距离近似只适用于CPI内位移相对距离分辨单元足够小等条件；否则应加入运动轨迹与距离迁移处理。

## 4. 正确的距离、速度坐标关系

设调频斜率S=B/T_chirp，有效采样率F_s'，距离FFT点数N_R，慢时间FFT点数N_D，同波束等间隔chirp重复间隔T_r，则：

- 距离频率bin间隔：Δf_b=F_s'/N_R。
- 常用单基地等效距离bin：ΔR_bin=cF_s'/(2SN_R)。
- 物理距离分辨率约c/(2B_eff)，其中B_eff=S·T_obs，T_obs为实际有效观测时长；全chirp时B_eff≈B。
- 多普勒bin间隔：Δf_D=1/(N_DT_r)。
- 对固定雷达、固定PMS、单RIS往返目标，径向速度标度为v_r=±λ_RF f_D/2，正负由混频定义及已知运动标定。
- 常用无模糊速度量级：v_max≈λ_RF/(4T_r)；真实速度分辨量级约λ_RF/(2MT_r)，M是实际相干样本数，不是随意零填充点数。

FMCW上扫时拍频还含Doppler项，f_b≈Sτ±f_D；高精度距离需处理距离—速度耦合。零填充只细化显示/插值网格，不增加物理带宽或CPI。

**同波束采样时序尤其关键。** 如果仅作示例，64波束各驻留30 µs后轮询一次，则重访间隔至少约1.92 ms，不能用30 µs算该波束速度轴；按3.35 GHz算出的速度无模糊量级约11.7 m/s。这个数只是所述假设下的计算，不代表原论文实际时序或其速度混叠。原文没有给出足够信息让我们据此认定实验混叠。

## 5. PMS潜望镜路径不能套用有源终端的一次反射模型

论文路径为：

```text
雷达Tx → PMS → 无人机 → PMS → 雷达Rx
```

设固定喇叭到PMS距离r_TP、r_PR，PMS到无人机距离d(t)，近似总路长：

```text
L(t)=r_TP+r_PR+2d(t)
tau=L/c
R_app=c·tau/2=d(t)+(r_TP+r_PR)/2
```

因此单基地方式显示的距离需扣除固定喇叭—PMS偏置才得到PMS到目标的距离；两侧均1.5 m时偏置约1.5 m。多普勒反映目标相对PMS的径向速度，不是无人机三维总速度，也未必等于相对雷达直线方向的速度。非固定PMS、不同站位或多路径时需要更完整的路径导数模型。

这一双程路径中表面散射起作用两次。固定同一码态并满足近似模式匹配时，若单程场幅度因子A<1，两程回波场会出现约A²的因素，功率约A⁴；真实有限孔径角度耦合还需完整建模。因此幅度吸收对无人机探测链路可能比一次反射通信更昂贵，不能只看单程幅度可调范围。

## 6. 移动场景与换码

先在一个CPI内固定波束/编码，再跨CPI扫描或更新。若需在CPI内切换，应按beam_id、码态、真实时间戳整理数据，并用复数响应补偿或非均匀采样算法；不能把不同编码下的相位跳变直接当成运动Doppler。

原CSV只有方向性幅度，没有换码复相位，不能直接完成这种去嵌入。单张RD图也不提供完整二维/三维位置；需额外角度估计、多波束比较或多站几何。论文使用幅度比较法估角，而非仅用距离—多普勒图恢复全部位置。

## 7. 与我们的8 GHz双谐振结构怎么衔接

新论文最值得借鉴的是角度稳定性和收发路径匹配。其单元使用对称结构、围腔和扰动过孔进行模式对齐，不是普通双条带；其角度稳定性不能直接继承到我们的8 GHz候选。

首轮仍先做8 GHz单元和有限阵列，但增加以下准入检查：6–10 GHz频散；两入射平面的0°/15°/30°及更大目标角度；交叉极化；固定R/C的相位随角度漂移；理想/封装/偏置三版本差异；双程损耗与真实孔径链路预算。若方位变化或角度漂移明显，需调整对称性和耦合结构，再考虑移动无人机实验。

3.35 GHz的方向图与8 GHz器件不能拼接成同一个真实实验。可分别作参考基线，或重设计统一频段并重新求解/标定；不能只改MATLAB的fc就把硬件迁移到8 GHz。

## 8. 推荐实验顺序和所需数据

1. 静态金属球/角反射器：校准路径、固定距离偏置、泄漏和噪声底。
2. 已知径向运动导轨：固定波束，检验速度符号、PRI、距离轴与检测门限。
3. 固定波束移动目标：逐步引入无人机散射变化，校验CPI和相干性。
4. 多波束扫描：记录每码状态和时间戳，验证DOA与跟踪，再进入NLOS无人机场景。
5. 若用于通感抗干扰论文，另加独立通信业务与可控干扰链路，报告BER/EVM/SINR；仅雷达RD图不能证明抗干扰通信。

至少需要：已解调相干IQ矩阵[N_fast,N_chirps,N_frames]（或原始ADC及解调流程），RF载频、斜率/带宽/有效chirp时长、实际Fs、触发与PRI、每个beam_id/码态/时刻、收发增益与功率、标定记录，以及独立目标位置速度真值。若只有RD图截图或CSV方向图，只能做局部解释，不能验证完整运动实验。
